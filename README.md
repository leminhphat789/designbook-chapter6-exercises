## cach chay

can jdk 17 tro len. mo terminal trong folder cua bai muon chay:

```powershell
cd 6.15
javac -encoding UTF-8 -d build *.java
java -cp build Main
```

thay `6.15` bang folder tuong ung. bien dich tung bai rieng vi cac bai su dung trung ten lop.
